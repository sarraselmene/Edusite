#  ProjectWeb — Site Web Éducatif

Un site web éducatif proposant des cours en ligne, développé avec HTML, CSS et JavaScript vanilla.

---

##  Aperçu

Ce projet est une plateforme web statique permettant aux utilisateurs de :
- Consulter des cours en ligne
- Créer un compte et se connecter
- Naviguer entre les différentes sections (accueil, cours, à propos, contact)

---

##  Structure du projet

```
projectweb/
│
├── index.html          # Page d'accueil
├── courses.html        # Page des cours
├── about.html          # Page à propos
├── contact.html        # Page de contact
├── login.html          # Page de connexion
├── signup.html         # Page d'inscription
│
├── web.css             # Styles globaux
├── courses.css         # Styles des cours
├── couses2.css         # Styles complémentaires des cours
├── login.css           # Styles de la page connexion
├── signup.css          # Styles de la page inscription
│
├── web.js              # Scripts JavaScript
│
└── imgs/               # Dossier des images
```

---

##  Lancer le projet

Aucune installation requise. Il suffit de :

1. Cloner le dépôt :
```bash
git clone https://github.com/ton-username/projectweb.git
```

2. Ouvrir `index.html` dans ton navigateur.
